What is Moderne?

Moderne builds the knowledge, discovery, and execution tools coding agents rely on to operate safely at scale. It's powered by OpenRewrite and the Lossless Semantic Tree (LST) — the industry's most comprehensive context model for understanding and transforming your code.

With Moderne, organizations automate framework migrations, remediate security vulnerabilities, and standardize code quality across thousands of repositories at once.

More about Moderne

  • Moderne Platform — enterprise-ready private SaaS for running recipes across your organization.
  • Moderne CLI — build LST artifacts and run recipes from your terminal.
  • Moderne DX — large-scale insights and remediation for air-gapped environments.
  • Moddy — a multi-repo AI agent pairing natural language with LST accuracy.
  • Prethink — recipes that generate structured context for coding agents.
  • IntelliJ plugin — create and debug recipes; search across all your repos.
