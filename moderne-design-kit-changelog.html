Design kit changelog

Every update to the design kit, brand guidelines, palette reference, and downloadable assets — newest first. The mint badges on the kit page point here.

July 24, 2026

Geist joins as the long-form body face New

New type rule: body copy up to about two sentences may set in Poppins; anything longer must set in Geist (--font-long). The Typography section gains a Long-form body · Geist specimen, and the skill bundle's tokens and rules teach the split to coding agents.

Logo showcards on cream New

The light showcards in the Logo section were still #F8F8FF blue-white; they now use the Morpheus cream #FBFAF6 so they sit naturally on the canvas.

Token tables follow the theme New

The Backgrounds & greys and Font colors tables no longer show both columns at once — in dark mode you see the dark values, in light mode the light values. Flip the theme toggle to compare. Product lockup downloads also joined the brand guidelines Downloads section.

Official product lockups New

The official Moderne + product lockup files (Platform Status and Documentation, white and Midnight versions) join the kit under assets/brand-guidelines/. The kit page's Logo section gains a "Moderne + product" row, and the brand guidelines Product lockups section now shows the real files — on light backgrounds the product name sets in slate #99A3B0 beside the Midnight logo.

Brand-asset rules for coding agents New

The skill bundle's SKILL.md and the starter kit's MORPHEUS.md now include a "Brand assets" section: agents must pick up the logo, DNA strand, and spectral bar from the design kit's hosted files — never redraw or recolor them — with the asset URL table, the Midnight/white color rule, clear-space and minimum sizes, and the product-lockup recipe.

Link accent is now true AAA blue New

The Morpheus light-mode link accent moves from #1055E2 (5.4:1 on the cream canvas — AA only, despite its label) to #1245AE (7.4:1 canvas / 8.1:1 card — AAA). Applied across morpheus.html, the design-kit library, Code Genome, and the tokens & starter downloads. Deep accent stays #16306B; info-toast blues are unchanged.

Design Kit skill bundle regenerated New

The .skill bundle's light tokens still carried the old cool greys (#F6F7FA / #ECEEF3 / #1B2230). Rebuilt with the Morpheus cream palette so agents given the bundle produce the current light mode.
