Login & token — flow storyboards

The same screens arranged as the actual paths a user takes. Screens repeat between flows on purpose — that's the point, to see each journey end to end. Every panel is the real server-rendered page; scroll a panel to see the rest of it.

Theme follows your OS light/dark setting. Part of the codegenome-auth prototype.

A · First-time user — GitHub / Google social login

A person's first social sign-in. They land on the token gate, then either grab a token (3a) or skip straight to the home page (3b). This is the only flow where the gate appears.

1 Sign in
Click Continue with GitHub (or Google) → authorize. → next: the gate.
2 First-time gate opt-in variant
Choose an outcome: Get my token (3a) or Skip for now (3b).
3a Token page Get my token
Reveal & copy the token (shown once). Close ✕ → home.
3b Home Skip for now
Home page (no token)
Skipping lands here — a token can be grabbed later from the profile menu.

Gate has two variants by region (auto-detected): opt-in (checkbox — EU & unknown) vs notice (no checkbox — US). Same token either way. Skip for now also sets a marker so the next sign-in skips the gate (Flow B).

B · Returning user — GitHub / Google social login

Any social sign-in after the first. The gate is skipped entirely — a plain login that lands on the home page.

1 Sign in
Click Continue with GitHub → authorize. → next: straight home (gate skipped).
2 Home profile menu open
Home page — profile menu open
No token prompt. A token is still one click away: the profile menu's Get a download token opens the token flow.

Getting a token as a returning user: they aren't sent to the gate on sign-in, but the existing Get a download token link in the profile dropdown (shown above) still takes them to the token flow whenever they want one.

"Returning" = a browser that already saw the gate once (a persistent cgp_returning cookie). Clearing it, or a new browser, shows Flow A again.

C · Licensed customer — username / password Moderne-provided account

Customers given a Moderne username & password sign in with those instead of GitHub/Google, and land on the token management page (generate / list / revoke). No gate.

1 Sign in
Enter the username + password Moderne provided → Sign in. → next: token management.
2 Token management
Generate a token, or revoke existing ones. Close ✕ → home.

Generating reloads this same page with the new token revealed once + Maven/Gradle/CLI snippets above the list. This is the closest thing today to your reference screenshot — Phase 2 generalizes it to social-login users and adds token names + expiry.
