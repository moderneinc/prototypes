Foundations

Tokens, made visible.

Every value below is a named token in ds-tokens.css. Swatches read live var(--ds-*) values, so they are always in sync. See Foundations · Colors for the full 10-ramp system, brand-exact stops, and the mapping from every semantic token to its ramp position.

Color model. The system uses 10 tonal ramps: neutral, warm-grey (structure) · red, gold (error, warning) · lime, green, teal, blue, violet, magenta (the 6 M-FISH brand strands). Primary/action = teal by default — the theme builder swaps it for any brand strand. Every semantic role is aliased to a ramp stop and shifted off brand-exact stops so no semantic token equals a brand-bright or brand-deep hex.
