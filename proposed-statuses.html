In-progress shapes indeterminate vs. determinate

Indeterminate · single item

Running Processing Syncing

Use when one item is working with no known internal progress (one repo: Running / Processing / Syncing · one LST building). Icon = loader-2, animated. Honors prefers-reduced-motion.

Determinate · aggregate across a known set

4 / 22 13 / 24 21 / 24
13 done2 failed5 running4 queued

X = repos that reached a terminal state · N = total. The fraction only climbs to N/N. Carry the good/bad breakdown as a separate rollup; when all N are terminal, the aggregate flips to its terminal status (Finished / Error / …).
