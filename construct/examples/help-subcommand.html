Subcommand help

Configure how mod connects to Moderne, your repos, and your build tools. USAGE mod config <subcommand> [flags] SETUP (required) moderne Connect to Moderne and authenticate. http Configure SSL trust store for HTTPS. recipes Configure where the CLI fetches recipes from. lsts Configure where the CLI stores LSTs. build Configure how the CLI invokes Maven and Gradle. AUTO-CONFIGURED cli CLI runtime defaults (usually fine as-is). log Logging level and rotation. OPTIONAL user User-level identity (overrides per-repo defaults). LEARN MORE Run mod config <subcommand> -h for details. Show all subcommands: mod config -h --all
Pattern: help-subcommand.md. Demonstrates triaged groups (SETUP (required) / AUTO-CONFIGURED / OPTIONAL) — user-role groupings, not alphabetical. Tokens: typography.section_header, color.semantic.info (subcommand column), color.text.supporting (descriptions, summary line).
